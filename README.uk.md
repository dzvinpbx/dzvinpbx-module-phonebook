[![GitHub release](https://img.shields.io/github/v/release/sanchozu/dzvinpbx-module-phonebook)](https://github.com/sanchozu/dzvinpbx-module-phonebook/releases)

**Українською** | **[Русская версия](README.ru.md)** | **[English](README.md)**

Модуль керування контактами для Dzvin PBX з автоматичним визначенням імені абонента на вхідних і вихідних дзвінках.

> Це форк модуля MikoPBX **ModulePhoneBook** для Dzvin PBX — див. розділ
> [Походження](#походження) нижче.

## Можливості

- **Визначення імені абонента** — автоматичний показ імені під час вхідних і вихідних дзвінків
- **Інтеграція із зовнішнім API** — пошук імені через зовнішні сервіси з кешуванням
- **Імпорт з Excel** — масове завантаження контактів із файлів Excel (.xlsx, .xls)
- **Веб-інтерфейс** — керування контактами через таблицю з пошуком і сторінками
- **Маска вводу** — автоматичне форматування номерів телефонів (необов'язково)
- **Багатомовність** — підтримка 26 мов

## Вимоги

- Dzvin PBX версії 2024.1.114 або вище

## Встановлення

1. Перейдіть у **Модулі** → **Маркетплейс** на панелі адміністрування Dzvin PBX
2. Знайдіть модуль **Телефонна книга**
3. Натисніть **Встановити**

Або встановіть із релізу GitHub:
1. Завантажте останній `.zip`-реліз
2. Перейдіть у **Модулі** → **Встановлення модуля**
3. Завантажте архів

## Використання

### Додавання контактів

1. Відкрийте модуль **Телефонна книга**
2. Натисніть кнопку **Додати**
3. Введіть ім'я та номер телефону
4. Натисніть Enter або клацніть поза полем, щоб зберегти

### Імпорт з Excel

Підготуйте файл Excel із двома стовпцями:

| Ім'я | Номер телефону |
|------|----------------|
| Іван Іванов | +380 67 123-45-67 |
| ТОВ «Компанія» | 380441234567 |

1. Перейдіть на вкладку **Імпорт**
2. Виберіть файл Excel
3. Натисніть **Імпортувати**

Номери телефонів нормалізуються автоматично — приймається будь-який формат.

### Пошук через зовнішній API

Налаштуйте зовнішній API для визначення імені абонента:

1. Перейдіть на вкладку **Налаштування**
2. Введіть URL API з плейсхолдером `%number%`:
   ```
   https://api.example.com/lookup?phone=%number%
   ```
3. Встановіть час життя кешу (у секундах, 0 = без кешу)
4. Натисніть **Зберегти**

API має повертати звичайний текст з іменем абонента.

#### Приклад запиту й відповіді API

Коли надходить дзвінок з номера **+380 (67) 123-45-67**, модуль нормалізує його в **380671234567**
і виконує HTTP GET запит:

**Запит:**
```http
GET https://api.example.com/lookup?phone=380671234567
```

**Відповідь (звичайний текст):**
```
Іван Іванов
```

Ім'я «Іван Іванов» буде показано як ідентифікатор абонента на телефоні. Якщо API повертає порожню
відповідь або помилку, модуль продовжує роботу без показу імені.

**Приклад з назвою компанії:**
```http
GET https://api.example.com/lookup?phone=380441234567
```

**Відповідь:**
```
ТОВ «Компанія»
```

Кеш зберігає відповідь протягом налаштованого часу життя, щоб зменшити кількість запитів до API
для номерів, що повторюються.

## Як це працює

### Нормалізація номерів

Номери нормалізуються для однакового зберігання й швидкого пошуку:

```
Ввід:   +380 (67) 123-45-67
Крок 1: 380671234567     (лише цифри)
Крок 2: 671234567        (останні 9 цифр)
Крок 3: 1671234567       (додано префікс "1")
```

Це забезпечує коректне зіставлення незалежно від формату набору номера.

### Потік дзвінків

**Вхідні дзвінки:**
```
Asterisk → AGI-скрипт → Пошук у PhoneBook → Встановлення CALLERID(name)
```

**Вихідні дзвінки:**
```
Asterisk → CONNECTED_LINE_SEND_SUB → Пошук у PhoneBook → Встановлення CONNECTEDLINE(name)
```

## База даних

База даних SQLite: `/storage/usbdisk1/dzvinpbx/custom_modules/ModulePhoneBook/db/module.db`

**m_PhoneBook** — контакти:
- `id` — первинний ключ
- `number` — нормалізований номер для пошуку
- `number_rep` — формат для показу
- `call_id` — ім'я контакту
- `search_index` — поле для повнотекстового пошуку
- `created` — часова мітка (для завершення терміну дії кешу API)

**m_ModulePhoneBook** — налаштування:
- `disableInputMask` — перемикач маски вводу
- `phoneBookApiUrl` — URL зовнішнього API
- `phoneBookLifeTime` — час життя кешу в секундах
